# 作者 v3 校勘参考：diando.net 作者处理方式

- 参考站：<https://www.diando.net/zuozhe/>（文学大家，2026-09-10 实测；仅取其**处理方式与人物归属**作校勘参考，不搬运其文本）。
- 观测结论：
  1. 按**朝代/国别**分组索引（先秦/春秋/…/近现代/当代；国别分类），每位作者有作品数（诗 N / 文 N）与简介；
  2. **同名作者各自独立**：以 slug `-2` 后缀区分（实测 `xie-tiao` / `xie-tiao-2`、`wang-bao` / `wang-bao-2` 分属汉代与南北朝），从不合并同名条目；
  3. 条目为**单一历史人物**（如韩愈：唐 768—824），可作「唯一人物」佐证。
- 应用到我方实体 v3 批次一（`authors-v3-candidates.tsv` 13 组）：
  - 采用 diando 规则：无同题重复证据者一律**保持独立**（12 组，含 qts 后缀消歧产物）；
  - 例外（有内部同题重复证据 + diando 唯一人物佐证）：`hanyu`↔`hanyu2`、`zhangji`↔`zhangji2`，落入 `people-merges.tsv` 白名单归并；
  - 归并依据是**作品同题重复**（异 id）而非推测，符合「不臆造」硬规；其余组待更强证据（生卒/小传/他源）再议。
